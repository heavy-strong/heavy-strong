### 안녕하세요, startxend입니다 👋

웹 서비스와 데스크톱 앱을 만드는 개발자이고, 요즘은 **AI · 머신러닝**에 빠져 있습니다.
대구소프트웨어고등학교(DGSW) 시절 PHP·Java로 시작해서, 지금은 TypeScript·React·Node.js로 제품을 만들고
이미지 생성 모델 학습, LLM 에이전트, AI 검색 같은 것들을 직접 돌려보며 공부하고 있습니다.

#### 🧠 AI · ML 관심 분야

- **이미지 생성 모델 학습:** Stable Diffusion LoRA 학습([sd-scripts](https://github.com/heavy-strong/sd-scripts), [Lora-Training-in-Comfy](https://github.com/heavy-strong/Lora-Training-in-Comfy))과 학습용 데이터셋 준비(이미지 캡셔닝·태깅)
- **ComfyUI 워크플로:** 노드 기반 이미지 생성 파이프라인 구성 및 커스텀 노드 수정
- **LLM 에이전트:** 코딩 에이전트([claw-code](https://github.com/heavy-strong/claw-code)), AI 튜터([DeepTutor](https://github.com/heavy-strong/DeepTutor))
- **AI 검색:** 셀프 호스팅 AI 검색 엔진([Vane](https://github.com/heavy-strong/Vane) + [SearXNG](https://github.com/heavy-strong/searxng))
